# 功能介绍

本文档记录当前项目已经实现的主要功能。

## 画布项目

- 支持创建多个画布项目。
- 支持项目重命名、删除、批量选择和批量删除。
- 支持单个或批量画布项目导出为 ZIP，也支持从 ZIP 导入画布。
- 画布项目保存在浏览器访客本地空间，暂不支持云同步。

## 无限画布

- 支持拖动画布、滚轮缩放、缩放滑杆和重置视图。
- 支持小地图定位，可开关小地图。
- 支持点阵、网格线、空白三种背景。
- 支持浅色和深色主题。
- 支持框选、多选、全选、取消选择、删除选中。
- 支持复制粘贴节点和节点之间的连线。
- 支持撤销和重做节点、连线、视口和背景变化。
- 支持节点连线，并高亮当前节点相关的上下游节点和连线。
- 支持快捷键帮助，覆盖缩放、框选、全选、复制粘贴、撤销重做、删除、退出选择和拖入图片。

## 节点

目前画布中有三类节点：

- 图片节点：展示上传图片、生成图片或素材库图片。
- 文本节点：保存提示词、说明文案、AI 文字回答等文本内容。
- 生成配置节点：汇总上游文本和图片，统一配置模型、比例、数量后批量生成图片或文本。

节点支持：

- 拖拽移动。
- 四角缩放。
- 图片节点等比缩放或自由比例切换。
- 查看节点基础信息和 JSON。
- 删除、复制、粘贴。
- 通过左右连接点建立上下游关系。

## 图片工作流

- 支持上传图片到新节点。
- 支持拖拽图片文件到画布。
- 支持替换已有图片节点内容。
- 支持下载图片节点。
- 支持把图片节点保存到“我的素材”。
- 支持图片裁剪，并把裁剪结果生成为新的图片节点。
- 支持本地多角度变换，并把结果生成为新的图片节点。
- 支持生成失败后重试。
- 批量生成多张图片时会先展示为图片组节点，支持叠卡预览、展开查看全部结果并设置主图。

## AI 生成

项目通过匿名后端代理访问管理员配置的 OpenAI 兼容渠道：

- `/api/v1/images/generations`：文生图。
- `/api/v1/images/edits`：图生图/参考图编辑。
- `/api/v1/chat/completions`：文本节点生成和带图节点问答。
- `/api/v1/videos`：视频生成。

可配置项：

- 管理员发布的图片、视频和文本模型。
- 图片质量。
- 图片比例。
- 生成数量。

普通图片/文本节点可以直接输入提示词生成结果。生成配置节点可以读取上游节点内容，并按节点自己的配置批量生成多个图片或文本结果。生成配置节点支持预览当前提示词和参考图输入，并调整输入顺序。

## 提示词库

前台提示词库支持：

- 按标题搜索。
- 按标签筛选。
- 按分类筛选。
- 查看提示词详情。
- 查看封面和结果图。
- 复制提示词。
- 把提示词加入“我的素材”。

后台提示词管理支持：

- 查询提示词。
- 新增、编辑、删除提示词。
- 按分组和标签筛选。

## 素材

“我的素材”是浏览器本地素材库，支持：

- 新增、粘贴和搜索图片素材。
- 图片按当前 Portal 用户的浏览器存储空间隔离。
- 上传时优先显示本地预览，并写入用户专属媒体记录。
- 按关键词搜索。
- 分页浏览。
- 拖入画布。

“公共素材”是全体 Portal 用户可读的图片库，支持：

- 搜索、分页和拖入画布。
- 浏览器优先读取本地图片缓存，缓存缺失时通过短期 URL 直连媒体存储。

后台公共素材管理支持：

- 仅 `portal-admin` 可上传或删除公共图片。
- 公共素材只保存图片；旧的服务器通用素材（文本、图片、视频）API 不再提供。

## 管理后台

- Portal Gateway 注入用户身份；仅 `portal-admin` 可访问管理后台。
- 管理后台包含 AI 供应商与公共图片素材管理。

## 后端能力

- Gin 提供 API 服务。
- Docker 运行时由 Next.js 提供页面入口，`/api/*` 请求代理到内部 Go 服务。
- GORM 管理数据库连接和自动迁移。
- 支持 SQLite、MySQL、PostgreSQL。
- 数据库保存系统设置、媒体记录和公共图片素材。
- `/api/v1/*` 根据 Portal 用户身份调用管理员配置的云端模型渠道。
- 业务接口统一返回 `{ code, data, msg }`。

## 当前限制

- 画布项目和“我的素材”目前只保存在浏览器本地，不支持云同步。
- 云端渠道 API Key 保存在后端私有设置中；图片生成、上传和访问均要求 Portal 身份。
- 公共图片由管理员上传到媒体存储，浏览器通过短期访问地址读取。
- 画布更适合桌面端使用，移动端触控体验还未系统完善。
