# 图片模型接入

## Maizi 协议与模型定义

`ai/providers/maizi.go` 负责请求发送、任务查询、状态和错误解析。
`ai/providers/maizi_image_models.go` 定义模型类型、接口地址、参数 Schema、规范化规则及固定请求字段。
同协议、同结果结构的模型在这里注册；不同协议不强行使用 Maizi 适配器。

旧类型 `maizi-image`、`maizi-seedream-5-pro-nsfw` 的 ID、规范化规则和原请求行为保留，保证已保存任务的 Schema 快照与幂等哈希可以重放。新增模型不能修改旧模型定义来替代注册。

`ImageRequestField.fixedOptions` 表示后台只能从模型声明的选项中启用子集。公开 Schema 保留后台配置顺序，并优先使用仍可用的模型默认值；否则使用首个启用选项。没有该标记的旧模型继续使用后台自定义选项及首项默认值。请求校验使用任务保存的 Schema 快照。

## Seedream 5.5

新增后台类型：`maizi-seedream-5-5`，建议模型名称 `seedream-5-5`。
接口地址固定为 `https://www.maizitech.ai/v1`，后台填写现有 API Key 和模型名称，不自动新增运行环境配置。

- 支持文生图和 0–10 张参考图，不支持遮罩。
- 分辨率：1K、1.5K、2K，默认 2K。
- 比例：1:1、4:3、3:4、16:9、9:16、3:2、2:3、21:9、2:1、1:2，默认 1:1。
- 输出：PNG（默认）、JPEG；背景：自动（默认）、不透明、透明。透明必须 PNG。
- 每次上游请求 `n: 1`，多张使用现有批量任务机制。
- 不发送 quality、nsfw_check、图层拆分、OCR 或提示词优化参数。
- 提交 `/images/generations` 后按 `data[0].task_id` 查询 `/tasks/{id}`，结果仍通过现有素材存储链路处理。

启用模型前按现有后台机制配置分辨率及记录单价、比例。记录金额不是供应商实际账单；本次不增加参考图附加费或新的计价规则。
工作流允许最多 11 个输入（例如 10 图加 1 文本），输出仍最多 9 个，具体图片数量继续受所选模型限制。

普通生图同时用于我的画布与自动化流程。本次不包含图层拆分、OCR、精确像素尺寸或新的数据表。

供应商文档：https://www.maizitech.xyz/docs/image-seedream-55
