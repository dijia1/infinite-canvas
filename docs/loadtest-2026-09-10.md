# infinite-canvas 10 / 30 / 50 人并发压力测试报告

测试日期：2026-09-10（Asia/Shanghai）。业务代码基线：`86ee114111f245eef2bb7ea819a32961241cee13`，本地 `main`。

## 1. 结论

在本次独立本地环境、50% 浏览 / 30% Canvas 编辑 / 20% Workflow 操作、编辑间隔 2～5 秒的模型下，10、30、50 人三档均完成。共记录 **29,493 次请求**，其中正常用户负载 **29,205 次，全部成功**；未出现非预期业务错误、HTTP 5xx、网络超时或数据一致性断言失败。

30 人档满足本次初始目标：普通 API p95 < 500 ms，Canvas / Workflow 保存 p95 < 1 s，5xx < 0.5%；50 人档同样通过。没有观察到连接池耗尽、服务崩溃、持续锁等待或旧版本静默覆盖。

这支持“相同环境和操作组合下，50 个活跃用户可稳定运行”的结论；不代表生产环境最大容量，也不覆盖真实 AI 供应商、浏览器渲染和实际大图传输。暂不需要为这次结果扩大连接池或修改核心架构。

### 业务响应与冲突单列

每档检查未登录 401 一次、普通用户访问管理员配置 403 一次，以及跨用户读取 Canvas / Workflow / Run 三次。当前三个跨用户拒绝接口返回 HTTP 200、正文 code=1、data=null；驱动同时检查 HTTP 和正文，只有预期权限探针允许这种响应，普通请求出现 code!=0 会记失败。

每档另外执行 10 轮相同 Canvas / 相同 revision 的两个独立会话竞争：共 30 轮、60 次竞争 PUT，恰好 30 次成功、30 次预期 409。每次都重新 GET，核对 revision 只增加 1，文档与获胜者一致。

三档合计 HTTP 4xx 为 36（3×401、3×403、30×409）；HTTP 200 的预期权限拒绝为 9 次。普通负载 4xx=0、5xx=0、正文业务失败=0、传输错误/超时=0。409 没有被算作系统故障，也没有被重试后掩盖。

## 7. 发现与后续建议

### 7.1 Canvas 保存包含大量逐媒体保留时间更新

累计 SQL 统计中，`UPDATE media SET expires_at=... WHERE id=...` 调用 **106,664 次**，数据库执行总计 4,337.63 ms，平均 0.04 ms。该累计文件包含初始化和三档测试，应与分档增量指标区别。

实际代码 [applyCanvasMediaChanges](/Users/Admin/codexprogram/infinite-canvas/repository/canvas_media.go:144) 会把保留媒体加入更新集合，再逐行 UPDATE；即使 expires_at 已经为 NULL 也仍写入。此项有直接代码和 SQL 证据，是优先评估的减少重复写入机会，但本轮没有证据表明它已经造成容量不足。

后续可单独评估仅更新实际发生变化的保留状态，并做 A/B 测试；必须保留媒体权限/有效性校验、稳定加锁顺序及与清理任务的事务协议。不能通过过滤节点或跳过媒体检查来提升压测数字。本次未实施优化。

### 7.2 列表响应随用户内容规模增长

[Canvas 列表查询](/Users/Admin/codexprogram/infinite-canvas/repository/canvas_project.go:114) 返回完整 document；[私有素材查询](/Users/Admin/codexprogram/infinite-canvas/repository/media.go:82) 没有分页。50 人稳定期仅 Canvas list 就返回 **177.70 MiB**，占该档正常 API 响应字节的 **45.8%**，且每人只有 3 张 Canvas。

这说明更大库规模可能先放大序列化、网络和内存成本，但当前测试仍通过。后续应先测试每人更多 Canvas / 数千素材，再决定列表摘要和分页方案；需要核查前端依赖，不能直接修改接口契约。

### 7.3 只监测 HTTP 5xx 不足以发现业务失败

[FailError](/Users/Admin/codexprogram/infinite-canvas/handler/response.go:36) 的部分错误使用 HTTP 200 + code=1。压测已把非预期正文错误纳入失败率。生产观测建议同时记录应用 code、Canvas 保存结果和耗时、409、DB 超时，避免把被拒绝的保存误记为成功。

### 建议的并发范围
