## 保留的边界

- Canvas 自动保存的请求 ID、回执、revision 和恢复协议保持独立；没有将它整体替换成 Workflow 保存协议。
- 图片、视频、公共图片、画布引用和工作流引用的授权与保留规则并不完全相同。本轮只合并已确认相同的规则，保留所有者/管理员权限、公共素材限制、对象版本、cleanup 状态与原有锁顺序。已有权限、版本身份、媒体删除并发与回滚测试覆盖这些边界。
- 全局容量是应用侧的调度额度。已进入 uncertain 的供应商请求仍可能在外部执行，因此它不代表供应商端绝对并发上限。恢复原任务要重新申请额度；不允许人工将任务直接标记为成功。
- 清理终态凭据不删除任务记录。原有统计和历史保留策略保持不变。
- 新增列是可重复的向前迁移。旧版本不会领取 paused 图片任务，回滚不会重新提交这些任务，但旧 UI 没有图片恢复入口。应由支持恢复的版本完成收尾，不能批量把 paused 改成 queued。
